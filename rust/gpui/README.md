# {{ project-name }}

A GPUI desktop application template using `gpui-kit`.

## Features

- **GUI Framework**: [gpui-kit](https://github.com/longbridge/gpui-kit) (GPUI) with component library and asset support
- **Workspace**: Multi-crate workspace (`{{ project-name }}-app`)
- **i18n**: [rust-i18n](https://github.com/longbridge/rust-i18n) with `zh-CN` / `en` locales
- **Logging**: `tracing` (stdout in debug, rolling files in release)
- **Single Instance**: `single-application` with unique instance ID (UUID generated by cargo-generate)

## Project Structure

```
.
├── {{ project-name }}-app/  # GPUI desktop application
│   ├── src/
│   │   └── main.rs
│   ├── assets/          # Embedded assets (rust-embed)
│   │   └── icons/
│   └── locales/         # i18n translation files (rust-i18n)
├── .github/
│   └── workflows/       # CI/CD pipelines
├── cargo-generate.toml
└── Cargo.toml           # Workspace root
```

## Quick Start

- Rust 1.85+

```bash
cargo run
```
